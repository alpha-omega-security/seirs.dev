Alessia Nardotto

Security Analyst, Incident Response & Vulnerability Management

Alessia Nardotto is part of the Eclipse Foundation Security Team, helping keep the open source projects hosted at the Eclipse Foundation, and their users, safe. She triages incoming vulnerability reports, coordinates disclosure between security researchers and project maintainers, and guides projects through embargoes and CVE assignment under the Foundation's role as a CVE Numbering Authority. With a background in back-end software development in Scala, she enjoys bridging the gap between security requirements and the developers who need to put them into practice.
